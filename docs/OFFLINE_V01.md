# v0.1: первый офлайн-срез (без почтовых API)

Реализована только безопасная локальная демонстрация, **не** production synchronization:

```bash
PYTHONPATH=src python -m mail_organizer sync --dry-run --fixture tests/fixtures/offline_messages.json --policy-dir policy
PYTHONPATH=src python -m unittest discover -s tests -v
```

Никакие OAuth, Gmail/Graph SDK, SSH или реальные серверные правила не используются. Фикстура содержит только искусственные признаки, число сообщений ограничено 100, неизвестные поля (включая body/HTML) отклоняются. Отчёт печатает **только агрегаты**, а не темы, идентификаторы или отправителей. SQLite создаётся **только в памяти** и не записывается на диск. Курсоры, события и схема решений представлены таблицами, но реальный provider adapter ещё не реализован.

## Приоритеты безопасности

- Метки `ChatGPT-Control` и любые дочерние `ChatGPT-Control/...` — абсолютный защищённый контур, не классифицируются обычными правилами.
- Политика содержит только правила с `ownership=managed`; существующие `external` правила почты не импортируются автоматически.
- Несовпадающие правила и неизвестные случаи возвращают `REVIEW_REQUIRED`; никакие инструкции в теме письма не исполняются.
- Каждое совпадение становится только `label_candidate`, фактически ничего не изменяется; в SQLite `actions` используется исключительно `dry_run`/`proposed_only`.
- Предложение не означает, что разрешено применять правило к реальной почте. Protected/hold/финансы/документы и специальные Gmail/Outlook labels нуждаются в отдельном полноценном policy gate до подключения API.

## Минимальный формат policy

`policy/rules.yaml` пока поддерживает **только JSON-синтаксис**, являющийся допустимым подмножеством YAML 1.2. Это временный выбор, позволяющий тестировать ядро без дополнительных зависимостей. Обычные YAML-отступы в текущем офлайн-срезе ещё не поддерживаются. Правила и вымышленные `.invalid` домены предназначены только для тестирования.

## Не готово

Real Gmail/Graph OAuth read-only, инвентаризация labels/folders/rules, полноценные `categories.yaml`/`protected.yaml`/`retention.yaml`/`control-queue.yaml`, более широкие детерминированные policy, recovery/audit, systemd timer, стабильный многодневный soak и Gate v0.1 → v0.2.

Файловое состояние для **отдельного режима искусственных страниц** описано в
[OFFLINE_STATE.md](OFFLINE_STATE.md). Ограничение «SQLite только в памяти» выше
относится к исходной команде `sync --fixture`; она сохраняет прежнее поведение.

Никаких изменений в Gmail, Outlook или VPS этот срез не разрешает.
